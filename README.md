# ResQFlow App

A self-contained hackathon prototype for the unified ResQFlow concept.

## Included
- Admin dashboard
- Hospital dashboard
- Ambulance/EMS dashboard
- Emergency Case ID lifecycle
- Hospital ACCEPT / ACCEPT WITH LIMITATION / DECLINE
- Dynamic re-evaluation
- Emergency Passport
- Case timeline / audit trail
- Hospital load awareness
- Referral continuity
- Simulated route + ETA updates
- Demo data and role-based views

## Run
Open `index.html` directly in a browser.

Demo logins:
- Admin: admin@resqflow.demo / admin123
- Hospital: hospital@resqflow.demo / hospital123
- Ambulance: ambulance@resqflow.demo / ambulance123

Data is stored in browser localStorage. Use "Reset demo" in the sidebar to restore the sample state.

This is a frontend prototype. For production, replace demo authentication, localStorage, simulated map/traffic, and static data with secure backend services, role-based authentication, realtime messaging, validated integrations, and audited data storage.
